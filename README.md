# Golden Eagle AI Terms

A one-concept-per-page teaching viewer for the Golden Eagle Programme (AI Dream Lab).
Each term shows its meaning, an everyday comparison, and a workplace example.

## Teaching shortcuts
- ← / → : previous / next term
- Q : quiz mode (hide the explanation), Space : reveal
- R : random term
- P : present mode (hide the index, larger text)
- / : search

## Deploy
- **Vercel (recommended):** import this repository in Vercel, framework preset "Other", no build command. `index.html` is served as the home page.
- **Streamlit Community Cloud:** create an app from this repository with `app.py` as the main file.

## Updating terms
Edit `index.html` on GitHub (the `TERMS` list near the bottom) and commit. Vercel redeploys automatically.
